# Runcrate Homebrew tap

Homebrew formulae for [Runcrate](https://runcrate.ai/?utm_source=github&utm_medium=homebrew&utm_campaign=homebrew-tap).

## Runcrate CLI

Deploy and manage GPU instances, SSH in with short-lived keys, copy files, and manage
workspaces, storage and billing from your terminal.

```bash
brew install aeonmindai/tap/runcrate
runcrate login
runcrate instances
```

Upgrade with `brew upgrade runcrate`. `rc` is installed as a shortcut for `runcrate`.

Source and releases: [aeonmindai/runcrate-cli](https://github.com/aeonmindai/runcrate-cli).

## How the formula stays current

`Formula/runcrate.rb` is generated by `bin/update-formula` from the checksums published
with each runcrate-cli release. The [Sync formula](.github/workflows/sync.yml) workflow
runs it when runcrate-cli publishes a release (repository dispatch) and every six hours as
a fallback, then installs and audits the result on macOS.
